# Employee Salary Prediction AI

This project uses a Decision Tree Classifier to predict employee salary categories (<=50K or >50K) based on various features such as age, education, and work experience.

## 📊 Model Performance
- Accuracy: 81.7%
- Algorithm: Decision Tree Classifier

## 🧠 Technologies Used
- Python
- Pandas
- Scikit-learn

## 📁 Files
- salary_model.py → Main model code
- salary_data.csv → Dataset used

## 🚀 How to Run
1. Install dependencies:
   pip install pandas scikit-learn
2. Run:
   python salary_model.py
